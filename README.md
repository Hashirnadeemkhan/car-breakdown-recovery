# Car Breakdown Recovery Leeds

Professional 24/7 car breakdown recovery and roadside assistance landing page built with modern web technologies.

## 🚀 Features

- **Animated Hero Section** - Impressive hero with professional imagery and floating stats
- **Service Showcase** - Display of all services with real professional photos
- **Photo Gallery** - Beautiful gallery with lightbox modal for image viewing
- **Why Choose Us** - Benefits section highlighting key advantages
- **Service Coverage** - Display of all areas served (Leeds, Bradford, Huddersfield, Sheffield, etc.)
- **Emergency CTA** - Multiple calls-to-action throughout the page
- **Floating Action Buttons** - Quick access to phone and WhatsApp
- **Professional Footer** - Complete business information with agency credit
- **Fully Responsive** - Works perfectly on mobile, tablet, and desktop
- **Smooth Animations** - Framer Motion animations for engaging interactions
- **SEO Optimized** - Proper metadata and JSON-LD schema
- **Modern Design** - Premium color scheme with brand blue and gold accents

## 🛠️ Tech Stack

- **Framework:** Next.js 14.2
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Images:** Next.js Image optimization

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Hashirnadeemkhan/car-breakdown-recovery.git

# Install dependencies
cd car-breakdown-recovery
npm install

# Run development server
npm run dev
```

Visit `http://localhost:3000` to see the landing page.

### Build for Production

```bash
npm run build
npm run start
```
